# 默认管理员密码重置工具

入口类：`org.token.tools.ResetDefaultAdminPassword`。

本工具由用户手工运行，用于把当前实例默认管理员 `admin` 的密码重置为本次明确提供的新密码。源码中不保存默认密码；未提供新密码时拒绝连接数据库。开发交付不等于执行，工具不会在应用启动时自动运行。

## 在 IntelliJ IDEA 中运行

1. 以当前服务端 `pom.xml` 打开 Maven 项目，使用 JDK 17，等待依赖索引完成。
2. 打开 `src/main/java/org/token/tools/ResetDefaultAdminPassword.java`，运行其 `main` 方法。
3. 工作目录设为当前 `token-server`。在运行配置的环境变量 `TOKEN_ADMIN_RESET_PASSWORD` 中填写本次新密码；也可传入一个新密码参数，显式参数优先于环境变量。不要把实际密码保存到仓库内的共享运行配置。
4. 工具成功后，使用账号 `admin` 和新的密码重新登录。旧 JWT 会因密码散列变化而失效。

此入口是普通 Java 主程序，不启动 `TokenApplication`、Spring 容器或后台任务。

## 配置来源与限定

- 优先读取工作目录下 `src/main/resources/application.yml`；在工作区根目录运行时，读取 `token-server/src/main/resources/application.yml`；找不到源码配置时，读取当前主类运行类路径中的 `application.yml`。
- 只读取 `spring.datasource.url`、`username`、`password`，并允许 `DB_URL`、`DB_USERNAME`、`DB_PASSWORD` 环境变量覆盖。环境变量必须配置在该主程序的运行配置中。
- 连接前要求 JDBC URL 明确指向 MySQL 的 `token`，事务内再执行 `SELECT DATABASE()` 校验实际库名。
- 行锁读取用户名为 `admin` 的候选；必须唯一，且满足当前实例已确认的 `uid=1`、精确用户名 `admin` 和默认管理员保护规则。
- 使用现有 `PasswordUtils` 生成 BCrypt，只更新 `ad_master.password` 一列。校验或更新失败时回滚事务；不会新增账号、修改角色、解除禁用或重置 TOTP。
- 新密码要求 6～64 字符，且 UTF-8 编码不超过 72 字节。参数和环境变量都未提供时立即失败；空白或格式不符也拒绝连接数据库。
- 控制台只显示中文结果，不输出密码散列、数据库口令或 JDBC 原始异常；配置文件不会被修改。

## 可选 Maven 命令

先在当前进程中安全设置 `TOKEN_ADMIN_RESET_PASSWORD`，再在当前服务端目录以 PowerShell 7 执行；不要将实际密码写入命令文件或提交到仓库：

```powershell
$env:JAVA_HOME = 'E:\Java\jdk\17'
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\mvnw.cmd -DskipTests compile exec:java '-Dexec.mainClass=org.token.tools.ResetDefaultAdminPassword'
```

Maven 的 `exec:java` 首次运行可能需要下载 `exec-maven-plugin`；离线环境直接使用上面的 IDEA 运行方式，无需引入新项目依赖或修改 `pom.xml`。

## 定向验证

`ResetDefaultAdminPasswordTest` 只使用 H2 内存库和测试配置，验证缺失输入不连接数据库、环境变量与显式参数优先级、BCrypt、只改密码、数据库双重守卫、默认管理员唯一性、环境覆盖和错误信息脱敏，不读取真实数据库配置、不连接真实 MySQL。

```powershell
.\mvnw.cmd '-Dtest=ResetDefaultAdminPasswordTest' test
```
