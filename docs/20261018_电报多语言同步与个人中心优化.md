# 电报、多语言同步与个人中心优化（2026-10-18）

本轮只吸收 `ref/credits-main` 中适用于 Token 的通知排版、翻译读取与漏键检测修复，并调整用户端导航及个人中心。没有执行真实数据库操作、发送电报或修改资金规则。

## 页面调整

- PC 顶部与手机底部主导航的钱包改为邀请，进入 `/team`；团队统计仍为 `/team/overview`。
- 身份信息旁显示当前服务端安全分，兼容数字文本，缺值不补造分数；点击进入安全中心。
- 我的资产下新增算力、项目、收益三钱包分布图，同时显示各钱包金额与比例。只采用真实可用金额，不包含冻结、在投本金或展示赠送；零余额显示空环，缺计价时不展示虚假比例。
- 图下提供充值、提款、划转；随后为邀请收益块，展示当前团队层数范围内累计到账邀请收益及累计邀请人数，整块进入团队统计。
- 四个快捷入口移至正文最底部，依次为钱包、流水、团队、活动中心。PC 左侧依次放资产、分布、邀请，右侧放功能列表，底部四快捷整行展示。
- 资产隐藏开关同时隐藏分布金额、比例、彩色扇区及邀请收益。换账号或离页取消读取，迟到数据不能进入新账号页面。

以上复用现有用户资料接口及代理层数口径，无新 API、权限或业务表字段。

## ref 同步范围

- 电报正文真实 LF/CRLF、段落及代码缩进在清理后保留，连续清理仍保持排版。预览和发送使用同一正文规范；预览标题内粗体使用行内样式。
- 模板测试默认优先选择启用的中文（包括地区码），其次英语，再首个语言；服务端省略测试语言时使用 `zh`。没有实际发送测试消息。
- type 1/5/7 译文在存在有效英语参照时检查参数集合和括号协议；缺参、多参、混入损坏括号时按原顺序回退。参数重排、重复及 Vue 合法字面插值继续支持；无有效英语参照保持原读取行为，不回写人工译文。正文缓存读取身份已更新。
- 有限键审计补齐条件展开、可选 `labelKey`、字段覆盖顺序及包装器识别。资产分布的跨函数钱包拼接键有闭合枚举契约，来源未知的动态表达式仍单独报告。
- 对照 ref 补缺清单后，仅新增当前使用的两个后台账本金额筛选键。未引入 ref 的旧运行频率键、停用奖励键、旧权限或独立配置路径。
