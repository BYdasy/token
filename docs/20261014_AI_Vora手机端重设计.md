# AI Vora 手机端重设计

本轮以 `Token_UI.docx` 的手机设计图和用户最新页面顺序要求重新组织用户端。项目技术名称仍为 Token，默认用户品牌 AI Vora，后台已配置的名称、Logo、图片和功能开关继续优先。

## 页面与公共样式

- 页面和顶部背景统一为 `#FDF1E9`，常规卡片为 `#FDFAF8`，品牌文字 `#3B142B`；主按钮采用 `#F0A887` 至 `#784352` 渐变和完全圆角。主题入口为 `token-user/src/styles/ui-layout.css`，规范为根 `DESIGN.md`。
- PC 继续使用五项顶部导航，手机使用对应底栏；语言入口为地球图标加完整名称，页脚仅保留平台名称。
- 登录注册重做为居中品牌、长下划线标签、等宽输入和整块底部背景。保持登录右侧放进入首页，删除底部重复注册引导；规则改为字段下可换行帮助。修正认证与安全页 scoped CSS 误生成裸 `#app` 的问题，实际输入外框为同宽、50px 高。
- 首页顺序为轮播、品牌简介、资产/累计收益/进行项目、五个快捷操作、项目和平台运行数据。移除公告列表，保留后台控制的内容弹窗和活动入口。进行项目读取服务端全部进行中订单总数，累计收益读取统计接口；没有新增默认平台运营数字。
- Token 重做为场景、当前等级与有效期、两项资产、四项收益/次数指标、带星图标的圆角执行按钮和最近收益。移除等级对比，保留当前等级详情和执行记录。最近收益读取本人的既有账本接口，固定计价优先，缺历史计价不按当前行情补算。
- 项目目录、详情、购买、订单、钱包、充提、划转、地址、记录、邀请、团队、个人、安全、设置、消息、帮助、安装及内容页面同步调整。钱包金额在放大时自然换列；项目卡在中等宽度改为单列，金额完整展示。
- 二级页删除重复的导航标题，项目及内容详情只保留自身返回；邀请二维码说明恢复横排。

主要变更集中于 `token-user/src/views`、`token-user/src/components` 和 `token-user/src/styles`。同时更新静态/动态 PWA 主题色和资源版本。没有增加依赖、权限码、真实支付操作或服务端业务接口。

## 旧样式清理

核对模板、路由、动态类名及测试依赖后，清理旧认证装饰、算力立方体/轨道和失效布局，合计移除125个无引用选择器分支；另外移除旧字母品牌渐变文字样式。三个目标样式文件执行前使用 AES-256-GCM 和当前 Windows 用户 DPAPI 加密备份，并完成磁盘解密与逐文件哈希核对。

本机证据：`.local/token-mobile-20261014/cleanup-backup/verification.json`、`legacy-style-cleanup.json`。资金、订单、账本和业务状态没有按界面显示范围清理。
