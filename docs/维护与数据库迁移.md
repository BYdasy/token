## 当前结构

配置统一 system_setting，每键 revision。奖励键 compute.reward.configuration，通知键 notification.automation.configuration；领域 JSON 含 configuration 和独立生效时间。写入由对应服务校验，普通设置不能绕过资金、奖励或通知权限。

管理员安全使用 admin_security，资料和范围标记使用 ad_master；多根范围使用 compute_admin_member_scope，唯一邀请关系为 compute_member.inviter_id。

产品仅 GPU，报价表 compute_product_quote；VIP 仅即时点击执行。钱包、账本、固定计价、有效支付归属、奖励和活动防重记录按各自粒度保留。

## 权限与多语言

当前权限树 docs/v23-permissions.json，仅当前叶子可授权。运行 node scripts/Audit-Permissions.mjs --check 验证 Java、前端和接口声明一致。

当前中英文输入为 docs/i18n/current-*-{zh,en}.json。运行 node scripts/Audit-TranslationKeys.mjs --check 检查静态及有限动态键；TranslationRuntimeContracts.mjs记录不能穷举的来源与保留边界，Plan-TranslationCleanup.mjs合并运行菜单、字典、通知及协议引用后生成精确(type,key)删除清单。不能仅凭当前数据库没有某枚举值或源码搜索无命中判断未使用。server.* 为 type1，admin.* 为 type5，user.* 为 type7，通知模板 type6；中文及内置模板受保护。词条与 i18n.translations.revision=LOWER(UUID()) 在同一事务更新。
