# 收益展示与视频交互优化（2026-10-18）

本轮调整用户端收益展示、等级拖动、首页视频，以及管理端公司文件上传与预览。未修改服务端结算、权限、业务表结构或实际数据库。

## 页面行为

- Token 页面在宽度小于 1024px 时只显示“收益记录”入口，继续进入 `/auto-records`，不加载最近收益。电脑保留最近三条，下方等级列表支持鼠标拖动，拖动后不误进详情，原点击、触摸、滚动条和键盘仍可使用。
- 算力提交和运行动画期间暂停最近收益读取，保留已有历史；动画结束后更新本页收益和资产摘要。重新进入页面先复核服务端运行状态，换账号和迟到请求不会混入旧记录。服务端仍即时结算，未延迟到账或改写账本。
- 首页视频先展示实际视频静帧或官方预览封面，点击播放。手机一次显示一张，左右滑动或使用前后按钮切换；电脑可并列，同页只激活一个播放器。切换、滑出、隐藏、离页或换账号时停止旧播放。
- PDF 与视频分开上传、分别检查格式和大小。PDF 保留下载操作，视频改为播放预览；视频首次上传后可直接在编辑表单中预览本次文件，已有文件复用原鉴权接口。
- 首次上传结束后再初始化编辑表单，兼容合法整数文本，标题、文件名、外链和排序分别提示。隔离测试中普通数值响应未复现原先的混合错误提示，不能据此认定线上故障的唯一根因；已覆盖首次直接保存和分页不含新上传项的路径。

上传及直链的封面来自浏览器读取的视频静帧；YouTube 使用官方缩略图，Vimeo 使用不可直接交互的官方预览。实际可播放性仍取决于视频编码、文件本身及第三方是否允许嵌入，失败时可重试。私有文件不改为公开文件，不向第三方发送用户凭据。
