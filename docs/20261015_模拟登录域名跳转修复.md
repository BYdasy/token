# 模拟登录域名跳转修复

日期：2026-10-15。本次修改管理端地址解析，不修改数据库、会员会话规则或服务端支付配置。

## 原因与修复

旧代码只去掉 `api.` 前缀。后台部署在 `https://xiongda.winter-mute.vip/` 时，模拟登录会再次打开后台，而不是用户端。

现在默认从浏览器当前后台域名识别可注册主域，不再依赖 API 地址。`xiongda.winter-mute.vip`、`api.winter-mute.vip` 及其他后台子域均默认进入 `https://winter-mute.vip/`。使用固定版本 `tldts@7.4.18` 处理 `co.uk` 等多级公共后缀，并保留 `github.io`、`pages.dev` 等托管平台的租户边界。解析在本地完成，不向外部服务发送域名或票据。

显式 `VITE_USER_APP_URL` 仍优先；开发环境使用用户端实际配置端口；IP、IPv6、localhost、单标签主机及生产非默认端口保留。用户站公共路径仍来自现有用户端构建配置。

一次性票据仍只放在 URL fragment 中，用户端在 Router 初始化前清除，只在内存消费一次。权限、代理范围、60 秒有效期、单次兑换和登录后替换旧会话均保持现有实现。分享链接复用修正后的用户入口，并继续清除票据及后台查询参数。

## 本次发布操作

在 `token-admin` 目录安装锁定依赖后重新构建管理端：

```powershell
pnpm install --frozen-lockfile
pnpm build:exp
```

按现有部署方式替换管理端构建产物，保持 `/token/` 静态路径，并刷新已打开的后台页面。本次无需重新构建用户端、替换服务端 JAR 或执行 SQL。本轮未执行打包或远程部署。

你当前的裸域用户站无需新增配置。若希望统一进入 `https://www.winter-mute.vip/`，可在管理端构建环境（例如 `token-admin/apps/web-ele/.env.production.local`）设置后重新构建：

```dotenv
VITE_USER_APP_URL=https://www.winter-mute.vip/
```

该变量是管理端构建配置，不属于 Spring YAML。裸域和 `www` 是不同浏览器 origin，登录状态各自独立；兑换成功后不应再通过前端把用户切到另一个域名。

用户站继续使用相对 `/api/compute`。各站 `/api` 应原路径代理到签发票据的同一 Token 服务及数据库，复用 [同源 API 代理片段](deploy/token-api-same-origin.conf)。不要把用户端 API 改为后台绝对域来绕过跳转问题。
