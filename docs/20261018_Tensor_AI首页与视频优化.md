# Tensor AI 首页与公司视频优化

本轮依据《网站需要修改的地方.docx》实施。用户已确认九家公司按“合作伙伴”展示，视频支持 MP4/WebM、YouTube/Vimeo 和 HTTPS 视频直链。2026-10-18 用户要求新增数据库变更全部交付 SQL 文件，本轮没有连接或修改真实数据库，没有打包、部署或 Git 提交推送。

## 已实现

- 默认品牌改为 Tensor AI，采用文档横版 Logo，并清理方形图标的棋盘背景，用于浏览器图标、安装图标、分享默认图片及管理端默认品牌。已有人工品牌配置继续优先，管理端保留原 Vben 主题。技术项目名、包名、数据库和兼容编码仍为 Token。
- 首页充值、提款独占一行，下方为关于我们、邀请好友、邀请团队、App 下载四个入口。资产区复用个人中心的组件，保留真实三钱包与法币折算；PC 右侧保留邀请入口。首页移除 GPU 项目列表，项目页保持可用。
- 视频放在平台运行数据上方；两端运行区均置于首页下方。合作伙伴位于首页底部，每行三家，通过现有模型供应商目录管理，只显示启用且配置了图片的供应商。
- 运行区仅展示算力、总容量、在线 GPU。默认算力区间 4.15～4.50 ExaFLOPs、总容量 5.0 ExaFLOPs、GPU 区间 10,900～20,000。数字变化间隔 `changeSeconds` 默认 2 秒、允许 1～300 秒；`refreshSeconds` 仍是 10～300 秒的配置同步间隔。服务端批量生成展示快照，浏览器播放，不每两秒请求接口。手动模式、暂停、页面隐藏、减少动态效果及不续会话等规则保留。
- 展示货币名称缺省为 USD，后台自定义名称仍有效。Token 算力、Token 收益等业务名称和模型 Token 用量保留；钱包编码、固定计价、余额、账本、报价与收益计算不变。

运行数值属于后台配置驱动的展示投影，不是新接入的硬件遥测，也不参与财务统计。

脚本包含 `USE token`、UTC、对象守卫和重复执行保护。它们经过静态审查，没有在真实 MySQL 执行验证。`token-schema.sql` 和测试结构已同步，但结构基线不应导入已有业务库。

## 后台配置入口

- 品牌：沿用管理端、用户端各自的网站品牌配置。
- 展示单位和运行区：系统设置中的用户端展示设置。SQL 保留原运行开关，需要展示时确认开关已启用。
- 合作伙伴：模型供应商的名称、图片、启用状态。默认 Logo 随服务端发布，通过固定白名单路径提供，不依赖外部图片站。来源与许可见 [partner-logos/README.md](../token-server/src/main/resources/partner-logos/README.md)。
- 视频：内容管理 → 公司文件。新增视频文件或视频链接，勾选“首页展示”并启用后才对游客开放。沿用公司文件权限 `71000` / `71001` 及全局管理范围。

公司资源包括 PDF、普通外链、视频文件和视频链接，类型不互改。PDF 限 20 MiB；MP4/WebM 限 100 MiB，服务端校验格式并随机命名存入私有目录。播放仍取决于浏览器支持的编码，上传校验不负责转码。其他网页链接作为普通外链打开，不嵌入任意网页，也不由服务端抓取外部视频。

首页视频列表最多 24 条，只返回启用且明确发布的视频；文件流每次重新核验状态，支持 GET、HEAD 和 Range。PDF、未发布视频及其他公司资源继续登录访问。点击后才加载视频或第三方播放器；私有视频通过带当前凭据的固定同源接口读取，有大小上限及取消处理，离开页面释放资源。已下载到客户端的公开内容无法通过后续停用撤回。

## 上传与分享部署配置

若实际运行配置仍限制单次上传为 20 MB，需要调整实际加载的配置。本轮只更新示例文件，没有修改本机或服务器真实配置：

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 100MB
      max-request-size: 110MB
```

Nginx 对应站点可按需设置 `client_max_body_size 110m;`，避免请求先被拒绝。文件仍位于原私有存储目录，不要把程序、密钥或私有文件目录设为网站根目录；视频通过 API 读取。

默认分享快照不再绑定旧站点域名。构建时可显式设置：

- `SHARE_PREVIEW_SETTINGS_URL`：用户站公开品牌接口，如 `https://实际用户站/api/system/settings/public`。
- `SHARE_PREVIEW_SITE_URL`：实际用户站根地址，用于将相对分享图片转换为公开绝对 URL。

未配置时保留 Tensor AI 标题和说明，不输出猜测域名的图片。品牌来源与处理说明见 [Tensor AI 品牌资源](branding/tensor-ai.md)。发布仍使用同批瘦 JAR 与 `lib`，两端同源 `/api`。
