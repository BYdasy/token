# AI Vora 交互与活动优化

日期：2026-10-14。本文只记录本轮新增修改；视觉沿用 `Token_UI.docx` 与已确认的 AI Vora 奶油杏色、暖白、深酒红及蜜桃至梅子渐变。

## 本轮完成

- 顶栏改用线条铃铛与新的地球轮廓图标；未读继续显示红点。游客顶栏给语言与登录留出空间，注册手机号移除静态帮助，校验错误保留。
- 首页轮播下展示最新公告标题与纯文字摘要，点击进入公告列表。项目卡移除冗余 AI 算力标签，保留独立横幅与真实产品信息。
- 币网、划转钱包、已绑地址与记录筛选改为控件下方就地展开，支持键盘、Escape 和点击外部关闭。划转双方钱包在选中状态和选项内显示真实可用余额，展开及回到页面时刷新。
- 资产页今日与累计收益块采用白色微透明背景。充值四步数字居中，以细竖线连接。
- 充提记录筛选为全部、成功、不成功；流水保留钱包与收入/支出筛选。三个记录标签均分，英文名称完整换行。筛选按钮读屏包含当前选项。
- 团队同一图表区切换邀请人数与收益趋势，共用 7/30/90 天。收益只取本人真实到账数据，缺计价或缺值不画虚假零值。
- 转盘与宝箱换成暖桃、梅子色舞台，统一次数栏、渐变图标操作、结果与记录界面；手机单列，PC 互动区和说明并排。
- 个人中心收紧用户名与 UID 间距，三钱包摘要左对齐，功能列表增加独立“平台公告”入口 `/announcements`。

## 接口与安全

`ComputeHomeQueryService` 在已有公开公告摘要中增加 `excerpt`，经 `ComputeContentHtml.excerpt` 提取可见文字，最多 160 个 Unicode 码点。摘要不返回 HTML、图片地址、内部字段或翻译中的源文；没有公告时前端不生成占位公告。游客访问边界保持原规则。

用户充值/提款列表新增可选 `statusGroup=SUCCESS|NOT_SUCCESS`，在 `ComputeCatalogRepository` 的同一 WHERE 中完成 COUNT 与分页过滤。成功口径沿用当前支付展示状态优先级；待处理归入“不成功”筛选组，每条记录仍返回原始真实状态。会员范围由认证身份决定，管理员原有 `status` 筛选不变。

无新增权限码，无新增表或字段。转盘八奖位、服务端中奖结果、次数、概率、账本与请求幂等未变；未触发真实抽奖、付款或通知。
